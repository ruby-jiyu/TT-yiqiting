# 一起听 — 酒馆网易云音乐助手（1.1.0）

SillyTavern 扩展。保留现有猫咪悬浮球与播放器，使用插件单独配置的 OpenAI 兼容 API，为角色生成推荐、喜欢的歌与歌曲评价。

## 安装 / 更新

将压缩包中的整个 st-netease-music 文件夹放进酒馆的第三方扩展目录：

    SillyTavern/public/scripts/extensions/third-party/st-netease-music/

也可以覆盖你原来安装此扩展的目录。保持一个安装副本，避免重复加载。目录中必须有 manifest.json、index.js、index.css。重启或刷新酒馆。

使用酒馆提供的 SillyTavern.getContext() 扩展接口；群聊暂不提供角色歌单生成，请打开单个角色聊天。

## 配置独立 API

打开猫咪播放器 →「登录」，或者酒馆「扩展设置」→「一起听」。

1. 填写 **网易云 API 地址**：你部署的 NeteaseCloudMusicApi 服务地址。电脑本机可填 http://localhost:3000；手机访问时填运行服务的电脑局域网 IP，例如 http://192.168.1.100:3000。
2. 填写 **AI API 地址、Key、模型名**。例：https://api.deepseek.com/v1，你的 Key，deepseek-chat。
3. 点击「保存 AI 配置」或「保存设置」，再点击「测试连接」。

AI 地址可以填写基础地址，例如 https://api.openai.com/v1，也可以填写完整的 https://api.openai.com/v1/chat/completions。如果供应商要求 /v1，请在地址中包含它。插件不会自动猜测供应商的路径。

这套配置独立于酒馆聊天模型。**无需先登录网易云就能配置和测试 AI。** 生成歌单同时需要可用的网易云 API，以查找真实歌曲；私人歌单通常需要网易云登录。

浏览器会直接请求你填写的 API，服务需要允许酒馆页面跨域访问（CORS）。手机上的 localhost 指手机自己；HTTPS 酒馆页面也可能阻止 HTTP API，服务地址需要与访问环境兼容。

## 角色联动

打开一个角色聊天 → 播放器「角色联动」。

- **他的推荐**：点击「生成推荐」，让 char 根据角色设定与最近六条对话为用户挑选歌曲。推荐理由使用角色口吻。
- **他的喜欢**：点击「生成喜欢」，让 char 根据自身性格选择喜欢的歌。重新生成会替换这个列表。
- 点击推荐卡上的 **♡ / ♥**，将歌曲加入或移出 char 喜欢的歌。也可以将播放器当前选中的歌曲加入，或从喜欢列表点击 × 移除。
- 登录网易云后，可以用下拉框将你的网易云歌单绑定为 char 喜欢的歌。绑定会把歌曲列表保存为当前角色的列表；之后手动修改会解除绑定。
- **他的想法**：让 char 用角色口吻评价前五首推荐 / 喜欢的歌。
- 酒馆扩展设置中可以关闭「切换角色后自动播放TA喜欢的歌」。

推荐、喜欢、评价按角色卡头像文件名分别保存到酒馆扩展设置，刷新后保留；同名角色不会互相覆盖。这些数据不会写回或随导出的角色卡携带。更换角色卡头像文件名后会视作新的角色。

歌曲必须在网易云搜索结果中匹配歌名与歌手才会加入，重复歌曲会合并；最终列表可能少于六首。歌曲搜得到不代表能播放，VIP、版权限制仍可能导致不可播放。

开启「一起听」后，插件通过酒馆扩展提示词接口告知角色当前歌曲；关闭后会清除提示，不修改聊天记录。点击分享按钮会把歌曲信息发送到聊天。

## 常见问题

**AI 测试失败？** 检查地址路径、Key、模型名、跨域设置和浏览器控制台。插件支持聊天补全接口，不使用 Responses 接口。

**AI 成功，但歌单生成失败？** 检查网易云 API 是否可访问、搜索是否返回正常 JSON；AI 返回的歌名和歌手也可能找不到。

**手机搜不到歌？** 将网易云 API 地址改为服务器 / 电脑可访问的地址，并检查防火墙。

**喜欢的歌为什么不跟着播放器变？** 角色喜欢的列表与播放器队列分别保存；播放搜索结果或用户歌单不会覆盖角色的喜好。
